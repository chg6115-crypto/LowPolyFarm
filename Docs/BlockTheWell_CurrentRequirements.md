# Block the Well — 사용자 직접 지시 우선 요구사항

사용자의 직접 지시가 기존 GDD와 참고 문서보다 우선한다. 아래 내용은 최신 사용자 지시를 기록한 것이며 구현 완료를 뜻하지 않는다.

## 스테이지와 종료
- `Docs/BlockTheWell_MapReferences.md`에 기록한 사용자 이미지 기반 텍스트 격자로 Stage 1~4를 구성한다.
- 기존 임시 3스테이지 배치는 최종 배치로 사용하지 않는다.
- 4라운드를 모두 클리어하면 게임 클리어로 종료한다.
- 라운드마다 클리어에 걸린 시간을 측정하고 화면 오른쪽 UI에 정리한다.

## 오브젝트와 이동
- 벽은 기존 바위 프리팹을 추가 배치해서 만든다. 검정색이며 움직이지 않는 장애물이다.
- 원본 바위 프리팹은 보존하고 벽 인스턴스/전용 머티리얼로 구현한다.
- 밀 수 있는 바위는 격자 단위로만 움직인다. 기존 GDD의 자유 물리 이동 규칙을 대체한다.
- 캐릭터는 격자 이동을 강제하지 않고 자유롭게 움직인다.

## 조작
- WASD: 캐릭터 이동.
- 마우스 우클릭 드래그: 시점 조작.
- 마우스 휠 클릭(가운데 버튼): 기본 시점으로 복귀.
- 휠 위/아래: 확대/축소.

## 사용자 조정 영역과 작업 원칙
- 조명, 카메라 구도, 배경은 사용자가 나중에 직접 조정할 예정이다. 임의의 연출 개선이나 재튜닝을 하지 않는다. 요청한 카메라 입력 기능과 Inspector 조정 가능성은 유지한다.
- 고정 오브젝트를 Hierarchy에 미리 배치하고 기존 씬·원본 에셋은 보존한다.
- 명시적인 요청 전에는 게임 검증·자동 플레이·빌드 테스트를 하지 않는다.

## 이번 확인 시점의 기존 구현
- `WellGame.ShowStage(index)`가 StageRoot 중 해당 인덱스만 활성화하고 나머지를 비활성화한다.
- 시작 시 `ShowStage(0)` 후 시작 화면을 표시한다.
- 현재는 임시 StageRoot 3개이며, 사용자 이미지 기반 4개 배치는 아직 적용 전이다.
- 클리어 시 성공 UI를 띄우며, NEXT STAGE 버튼을 누르면 다음 StageRoot로 전환한다. 성공 즉시 자동 전환하는 방식은 아니다.
- 기존 마지막 단계에서는 최종 성공 UI를 띄운다. 4라운드 확장, 라운드별 시간 UI, 격자 바위 이동, 검정 고정 바위 벽, 휠 클릭 복귀는 별도 구현이 필요하다.
