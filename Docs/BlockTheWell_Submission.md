# 수행평가 제출 안내 — Block the Well

## 실행
- Unity에서 `Assets/01_Scene/BlockTheWell.unity`를 열고 Play → START.
- WASD 이동, 우클릭 카메라 회전, 휠 줌, R 현재 스테이지 재시작.
- 바위를 우물 가운데로 밀고 잠깐 멈추면 고정됩니다. 스치거나 캐릭터만 들어가는 것은 성공이 아닙니다.
- 성공 화면 NEXT STAGE로 진행. 마지막 단계는 두 우물을 모두 막아야 합니다.
- Windows 빌드: `LowPolyFarm > Block The Well > Build Windows`. 결과 폴더 전체를 제출해야 합니다. exe만 따로 복사하지 마세요.

## 풀이와 영상 구성 (약 90초)
1. 시작 화면·조작 안내 (5초).
2. Stage 1: 바로 앞 바위를 우물 방향으로 밀기. 중심에 도착하면 멈춰 성공 확인 (15초).
3. R을 눌러 위치와 목표 상태가 복구되는 장면 (5초).
4. Stage 2: 바위 오른쪽으로 돌아가 왼쪽으로 밀고, 장애물의 왼쪽으로 우회해 북쪽으로 이동. 다시 왼쪽으로 돌아가 바위를 오른쪽 우물 중심으로 밀기 (30초).
5. Stage 3: 왼쪽 바위를 왼쪽 우물에 밀어 1/2 확인. 뒤로 돌아 오른쪽 바위도 오른쪽 우물에 밀어 2/2 확인 (25초).
6. 최종 승리 화면·다시 시작 버튼 (10초).
