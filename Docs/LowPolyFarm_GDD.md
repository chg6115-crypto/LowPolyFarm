# LowPolyFarm 기획 문서 (GDD v0.1)

> 가제: **남의 밭이 더 맛있다**
> 엔진: Unity 6000.6.0f1 / URP 17.6
> 프로젝트 경로: `C:\UnityProject\LowPolyFarm`
> 작성일: 2026-10-16

이 문서는 Claude Code가 구현 작업을 할 때 기준으로 삼는 기획 문서입니다.
**[확정]**은 기획자가 정한 내용이고, **[제안]**은 기본값으로 쓰되 Inspector에서 조정 가능하게 만들어야 하는 값입니다.

---

## 1. 한 줄 컨셉

겉보기엔 평화로운 힐링 농장 게임이지만, 실제로는 이웃이 내 작물을 서리해 가고 우물을 바위로 막아버리는 **2~4인 온라인 경쟁 농사 게임**. 화나지만 웃긴 캐주얼 게임.

- [확정] 아트는 힐링 게임처럼 아기자기하고 평화롭게 간다. **겉모습과 실제 플레이의 괴리**가 웃음 포인트다.
- [확정] 과장된 연출은 리액션 수준으로만 쓴다(머리 위 "?!", 기절 별, 효과음 등).

## 2. 승리 조건과 핵심 루프

- [확정] **짧은 라운드**. 라운드 종료 시 **돈이 가장 많은 플레이어가 승리**.
- [제안] 라운드 길이 5분.
- [확정] 돈을 버는 방법은 두 가지이며, 버는 돈은 같다.
  1. **내 농사**: 작업 반경(밭)을 넓혀가며 심고 거둔다. 안전하지만 느리다.
  2. **서리**: 남의 작물을 훔쳐 판다. 빠르지만, 잡혀서 **기절하면 시간을 잃는다**(리스크).
- [확정] 돈은 투자에 쓸 수 있다. 쓴 만큼 최종 점수는 줄어든다. "지금 투자 vs 모아두기"가 고민 포인트다.

```
밭 갈기 → 작물 묻기 → 물 주기 → 대기 → 2~5배 수확 → 창고에서 판매 → 투자 또는 저축
                     ↘ 남의 밭 서리 (리어카 / 은신) ↗
```

## 3. 맵

- [확정] 마을 전체를 **4분면**으로 나눈다. 플레이어 1명당 한 구역.
- [확정] 각 구역 구성
  - 플레이어 시작 지점: **창고 + 농기구가 있는 공간**
  - **우물 1개**
- [확정] 맵 **중앙에 작은 연못**.
- [제안] 구역 사이와 연못 주변에는 풀숲 지대를 둔다. 잠입 루트이자 확장 가능한 땅이다.
- [제안] 4분면은 길(흙길)로 구분하고, 각 농장 경계는 울타리 일부와 표지판으로 표시한다.
- 참고: 땅따먹기는 영토 점령 규칙이 아니라 **자기 작업 반경을 넓혀가는 것**을 뜻한다.

## 4. 농사 규칙

- [확정] **괭이로 갈아놓은 땅에만** 농사가 가능하다.
- [확정] 씨앗은 따로 없다. **농산물 자체를 갈린 땅에 놓으면 땅에 묻힌다**.
- [확정] 묻힌 칸에 **물을 주면**, 시간이 지난 뒤 땅 위로 올라오며 **2~5배**로 돌아온다.
- [제안] 배수는 2~5 사이 랜덤이다. 작물 종류별로 가중치를 다르게 둔다.
- [제안] 물을 안 준 칸은 자라지 않는다. 물을 준 칸은 흙 색이 진해진다(젖은 흙 머티리얼).
- [제안] 연출: 묻을 때는 땅속으로 가라앉고, 다 자라면 "뽁" 하고 여러 개가 튀어 오른다. 단계별 성장 모델 없이 코드 연출로 처리한다.
- [제안] 그리드는 기존 `FenceSystem`의 ground tile 그리드와 같은 칸 크기를 쓴다.

### 4.1 물

- [제안] 우물에서 물 도구(양동이 또는 물뿌리개)로 물을 길어 온다. 한 번 길면 N칸에 줄 수 있다(기본 3칸).
- [제안] 중앙 연못에서도 물을 뜰 수 있다. 다만 멀다. 우물이 막혔을 때의 대안이다.

### 4.2 작물 (초기 제안)

| 이름 | 판매가 | 구매가 | 성장 시간 | 배수 가중 |
|---|---|---|---|---|
| 기본 작물 (당근류) | 10 | 상점 판매 안 함 (시작 지급) | 20초 | 2~3배 위주 |
| 중급 작물 (양배추류) | 25 | 40 | 35초 | 2~4배 |
| 고급 작물 (호박류) | 60 | 100 | 50초 | 3~5배 |

- [제안] 라운드 시작 시 각자 기본 작물 3개를 지급한다.
- 모든 수치는 ScriptableObject(`CropData`)로 빼서 조정한다.

## 5. 창고 (판매 + 상점)

- [확정] 시작 지점에 창고가 있다.
- [제안] 창고에 작물을 넣으면 즉시 판매되어 돈이 된다.
- [제안] 창고 상점에서 살 수 있는 투자 항목

| 항목 | 효과 | 제안 가격 |
|---|---|---|
| 비싼 작물 | 중급·고급 작물 구매 | 표 4.2 참고 |
| 도구 강화 | 괭이·낫·물 도구 작업 속도 또는 범위 증가 | 50 |
| 울타리 재료 | 기둥 설치 개수 추가 | 기둥 5개당 20 |
| 리어카 | 리어카 1대 추가 | 80 |
| 개 사료 | 일정 시간 개 감지 범위 증가 | 30 |

## 6. 방해(공격) 요소

### 6.1 우물 막기
- [확정] 바위를 **밀어서(Push)** 상대 우물을 막을 수 있다.
- [제안] 바위가 우물 입구 판정 영역 안에 있으면 그 우물에서 물을 길 수 없다.
- [제안] 막힌 쪽 대응: 바위를 다시 밀어내거나, 곡괭이로 여러 번 쳐서 깬다. 깬 바위는 일정 시간 뒤 맵의 다른 곳에 재생성된다.
- 기존 `Pushable` + `PlayerMovement` 밀기 로직을 활용한다.

### 6.2 풀숲 은신
- [확정] 무성한 풀숲에서 **Ctrl로 기어 다니면**, **2~3m 이내가 아닌 이상 보이지 않는다**.
- [제안] 판정: 풀숲 트리거 영역 안 + 기기 상태일 때 `Hidden`. 다른 플레이어의 클라이언트에서 거리가 2.5m보다 멀면 렌더러를 숨긴다(이름표 포함).
- [제안] 기기를 풀거나, 작물을 뽑거나, 리어카를 밀면 은신이 즉시 해제된다.
- 기존 Ctrl 토글 기기, 기기 상태 캡슐 변경, 머리 위 막힘 체크를 그대로 쓴다.

### 6.3 서리
- [확정] 남의 밭에서 다 자란(땅 위로 올라온) 작물을 가져와 내 창고에서 팔면 돈이 된다.
- [제안] 손으로는 최대 2개까지 들 수 있다.
- [확정] **리어카에 담아** 대량으로 훔쳐 올 수 있다(→ 7장).

### 6.4 울타리 밑 통과
- 기존 울타리의 아래 가로대 높이는 기어서 통과할 수 있게 맞춰져 있다. 울타리는 완벽한 방어가 아니라 **침입을 느리게 만드는 장치**다.

## 7. 리어카

- [확정] 애셋의 Wheelbarrow(`LowPolyVehicleStarterPack`)를 리어카로 쓴다. 작물을 담아 남의 것을 훔쳐 올 수 있다.
- [제안] 용량 10개.
- [제안] 미는 동안의 제약
  - 걷기 속도만 낼 수 있다.
  - 기기와 은신이 불가능하다. 세워둔 리어카는 풀숲에 숨겨둘 수 있다.
  - 덜컹 소리가 나서 개 감지 범위가 1.5배가 된다.
- [제안] 미는 애니메이션은 기존 Push 클립을 쓴다.
- [제안] 리어카를 밀다가 기절하면 리어카가 엎어지고 실린 작물이 **전부 쏟아진다**. 누구든 주울 수 있다.
- [제안] 리어카 자체도 훔칠 수 있다. 남이 세워둔 리어카를 끌고 가면 된다.
- [제안] 시작 시 1인 1대. 추가 구매 가능.

## 8. 방어 요소

### 8.1 풀 깎기
- [확정] 농장이 털리지 않으려면 **풀을 깎아야 한다**. 풀숲이 잠입 루트가 되기 때문이다.
- [제안] 깎인 풀은 시간이 지나면 단계적으로 다시 자란다(짧음 → 중간 → 무성). **무성** 단계에서만 은신이 가능하다.
- [제안] 낫으로 깎는다. 깎는 데 쓰는 시간이 곧 농사 시간 손실이다.

### 8.2 강아지
- [확정] 농장마다 개가 있고, 농장에 **침입자가 발생하면 짖기 시작한다**.
- [제안] 은신 중인 침입자도 감지한다(감지 반경 기본 6m). 짖으면 주인 화면에 경고와 방향 표시가 뜬다.
- [제안] 개는 침입자를 향해 서서 짖기만 한다. 공격은 하지 않는다.
- [제안] NavMesh 기반으로 자기 농장 안을 배회한다. AI Navigation 패키지가 이미 설치되어 있다.
- [제안·추후] 뼈다귀(Pandazole `Bones`)를 던져 상대 개를 잠시 유인한다.

### 8.3 울타리
- 기존 `FenceSystem` / `FencePlacer` / `FencePost`를 그대로 쓴다(B: 건설 모드, 좌클릭 설치, X/Del 철거).
- [제안] 울타리 기둥은 재료 개수만큼 설치 가능하며, 재료는 상점에서 구매한다.

## 9. 잡기와 기절

- [확정] 도둑이 잡히면 **기절**한다.
- [제안] 주인(또는 아무 플레이어)이 근접 밀치기(공격 키)로 맞히면 대상이 3초 기절한다.
- [제안] 기절하면 들고 있던 작물을 바닥에 떨어뜨린다. 리어카 중이면 엎어진다.
- [제안] 기절 후 2초 동안은 다시 기절하지 않는다(연속 기절 방지).
- [제안] 연출: 머리 위 별, "띠용" 효과음, 털린 쪽은 Scratching(머리 긁기) 리액션.
- [제안] 도발 이모트: Hi(손 흔들기).

## 10. 네트워크

- [확정] **온라인 멀티플레이**, 2~4인.
- [제안] **Netcode for GameObjects + Unity Multiplayer Services**(Relay + 세션 참가 코드). 방장이 호스트를 맡는 Host-Client 구조.
- [제안] 권한 구조
  - 플레이어 이동: Owner 권한(CharacterController 기반이라 클라이언트 예측이 자연스럽다).
  - 작물, 밭 칸 상태, 돈, 리어카, 바위, 우물 막힘, 기절 판정, 라운드 타이머: **서버 권한**.
- [제안] 은신 렌더링은 각 클라이언트가 로컬에서 거리를 계산해 처리한다. 캐주얼 게임이므로 치트 방지는 고려하지 않는다.
- 현재 프로젝트에는 네트워크 패키지가 없다. 1단계에서 설치한다.

## 11. 조작 (기존 + 추가)

| 키 | 동작 | 상태 |
|---|---|---|
| WASD | 이동 | 기존 |
| Shift | 달리기 | 기존 |
| Ctrl | 기기 토글 | 기존 |

| 넘패드 0~9 | 애니메이션 디버그 메뉴 | 기존 |

참고: 건설 모드의 좌클릭과 도구 사용 좌클릭이 겹치지 않도록, 건설 모드일 때는 도구 사용을 막는다.

## 12. 현재 프로젝트 상태

### 12.1 기존 스크립트 (`Assets/02_Scripts`)
- `PlayerMovement.cs`: WASD 이동, Shift 달리기, Ctrl 기기 토글(머리 위 막힘 체크, 캡슐 높이 변경), Pushable 밀기와 Push 애니메이션, in-place 애니메이션
- `OrbitFollowCamera.cs`: 우클릭 오빗, 휠 줌. PlayerMovement가 카메라 방향을 기준으로 움직인다.

- `CharacterMotionDebug.cs`: 넘패드 애니메이션 테스트
- `Low.cs`: 빈 템플릿. 삭제 후보.

## 13. 구현 단계

각 단계는 다음 단계로 넘어가기 전에 플레이해서 확인할 수 있는 상태여야 한다.

1. **네트워크 뼈대**
   - NGO와 Multiplayer Services 설치, 세션 생성·참가 코드 UI(임시)
   - 기존 플레이어 이동, 기기, 밀기, 애니메이션 동기화. 카메라는 로컬 플레이어만 따라간다.
   - 완료 기준: 2개 클라이언트(ParrelSync 또는 Multiplayer Play Mode)에서 서로 움직이는 것이 보인다.
2. **맵 블록아웃**
   - 4분면, 시작 지점(창고 자리 + 농기구), 우물 4개, 중앙 연못, 풀숲 지대, 스폰 포인트

## 14. 작업 규칙 (Claude Code 참고)

- 기존 스크립트를 수정할 때 **Inspector에서 조정해둔 값을 덮어쓰지 않는다**. 기획자가 준 튜닝 값은 코드 기본값에도 반영한다.
- [제안]이 붙은 수치는 전부 `[SerializeField]` 또는 ScriptableObject로 노출해 Inspector에서 조정 가능하게 만든다.
- 새 스크립트는 `Assets/02_Scripts` 아래에 기능별 하위 폴더로 정리한다(예: `Network/`, `Farming/`, `Economy/`, `Sabotage/`, `AI/`, `UI/`).
- 프리팹은 `Assets/03_Prefabs`에 둔다(현재 비어 있음).
- 서드파티 애셋 폴더(`Pandazole_Ultimate_Pack`, `LowPolyVehicleStarterPack`, `Veresen`, `VARCO_URP`)의 원본은 수정하지 않는다. 필요하면 프리팹 베리언트를 `03_Prefabs`에 만든다.
