# Single — 시간 제한 없는 자유 농장

`Assets/01_Scene/Single.unity`를 열고 Play. 또는 `LowPolyFarm > Single > Open Single Scene` 메뉴 사용.
바닥, 집, 우물, Player 프리팹 인스턴스, 괭이, 카메라, 조명, 경계는 Single 씬 Hierarchy에 미리 배치되어 있습니다. 위치와 참조는 Edit 모드에서 직접 조정합니다. Play는 이 배치를 다시 생성하지 않습니다. 밭과 작물은 플레이/저장 상태에 따라 생성되며 UI는 OnGUI로 표시됩니다. 기존 Main/네트워크/농사 스크립트와 패키지는 수정하지 않습니다.
플레이어는 `Assets/03_Prefabs/Player.prefab`을 그대로 인스턴스화하고 기존 PlayerMovement와 Animator 설정을 사용합니다. 싱글 인스턴스의 네트워크 컴포넌트만 비활성화합니다.
우물과 흙은 `04_Models/StoneWell`, `04_Models/Soil`의 프리팹을 사용하고 괭이는 `Veresen/BasicTools/Prefabs/hoe.prefab`을 사용합니다. 원본 머티리얼을 교체하거나 URP 변환하지 않습니다.

1. 시작 위치에서 창고에 접근해 E. 시작 당근 3개를 최대 2개씩 꺼냅니다.
2. 노란 경계 안으로 이동. 가까운 땅에 마우스를 대고 1 + 좌클릭으로 갈기.
3. 2 + 좌클릭 또는 E로 농산물을 묻기.
4. 우물 가까이에서 E로 물 3칸분 보충. 3 + 좌클릭/E로 물주기.
5. 당근 20초 / 양배추 35초 / 호박 50초 후 작물 도구나 E로 수확.
6. 창고에서 판매 후 양배추·호박 구매 또는 밭 확장.

WASD 이동, Shift 달리기, 우클릭 드래그 회전, 휠 줌, Esc 일시정지, F5 저장.
작물이 남은 칸에서는 수확이 우선입니다. 모두 수확하면 다시 심을 수 있습니다.
창고 UI에서도 작물은 성장하고, Esc 일시정지 중에는 성장하지 않습니다.

`Assets/12_Settings/SinglePlayer/SoloSettings.asset`에서 가격, 성장 시간, 2/3/4/5배 수확 가중치, 상호작용 거리, 도구 부착 위치 등을 조정합니다. 이동 속도는 기존 Player 프리팹 설정을 사용합니다.
시작 밭은 7×7, 50원당 반경 1칸 확장, 최대 19×19입니다. 새로 확장된 땅도 괭이질이 필요합니다.
기본 작물은 판매하지 않습니다. 모든 작물을 소진하고 중급 작물을 살 돈도 없을 때만 재시작용 당근을 받을 수 있습니다.

자동 저장 30초, 창고 닫기, 플레이 종료 시 저장. `Application.persistentDataPath/LowPolyFarm_SinglePlayer_v1.json` 사용.
이전 파일은 `.bak`으로 보관합니다. 손상된 저장은 자동으로 덮어쓰지 않으며 창고의 새 농장 확인으로 초기화합니다.
밭·성장 진행·손에 든 작물·물·보관 작물·돈·확장 상태를 저장합니다. 오프라인 성장과 캐릭터 위치 저장은 없습니다.

검증 메뉴: `LowPolyFarm > Single > Validate Farming Loop`.
집과 UI는 기능 검증용 임시 표현입니다. 리어카·동물·울타리·방해 요소는 이번 농사 루프 범위에 포함하지 않습니다.
Multi 씬 및 게임 시작 화면의 모드 전환은 멀티 작업과 추후 연결합니다.
